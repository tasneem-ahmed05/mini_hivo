## Root cause and attempted correction

Original [project_understanding.py](../../hivo/project_understanding.py) recognized explicit new-project phrases such as `from scratch`, but `_GREENFIELD_RE` did not recognize a build request **in this empty workspace**. Meanwhile `_MODIFICATION_RE` matched terms such as `current`, `preserve` and `modify` inside the requested new game's requirements. The resulting existing-project mode triggered a legitimate evidence gate on an empty tree.

The defect was the mode decision, not the fact that existing-project reconnaissance refused to invent repository evidence. No evidence gate was bypassed.

The attempted next correction expanded greenfield recognition to a bounded build/create/develop/implement phrase followed within 160 characters, within a sentence, by an empty/blank workspace/directory/folder. Existing meaningful files still took precedence in the tested implementation. Tests also covered an empty workspace request to fix a missing existing target.

This source change and its new `test_greenfield_request_scope.py` file were used locally in Runs 005–006, but are **withheld from PR #2**. Subsequent review showed that a bounded phrase can still be incidental to explicit existing-project intent.
